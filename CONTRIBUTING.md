# Contributing to GradePilot

thanks for considering contributing.

## how to contribute

1. **fork and clone** the repo
2. **install** — `npm install`
3. **run locally** — `npm run dev`, open http://localhost:3000
4. **make changes** — keep them focused; one feature or fix per PR
5. **test** — run `npm run build` and `npm run lint` before submitting
6. **open a PR** — describe what you changed and why

## what we welcome

- bug fixes
- UI/UX improvements
- accessibility improvements
- docs fixes
- new features (open an issue first to discuss)

## code style

- we use ESLint; run `npm run lint` before committing
- keep it simple — readable over clever
